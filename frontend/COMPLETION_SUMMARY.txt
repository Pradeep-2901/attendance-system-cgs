📞 TROUBLESHOOTING QUICK FIX:
================================================================================

  "Cannot connect to backend"
  └─ Check if Flask app.py is running on correct port
  └─ Verify API_BASE URL in js/api.js

  "CORS error in console"
  └─ Ensure CORS(app) is in Flask app.py
  └─ Check after_request headers configuration

  "Login fails silently"
  └─ Check Network tab (F12) for 403/401 responses
  └─ Verify credentials exist in database

  "Photos not uploading"
  └─ Grant browser camera permission
  └─ Check if UPLOAD_FOLDER exists in Flask

  "Session expires on refresh"
  └─ Check Flask session configuration
  └─ Verify SESSION_COOKIE settings
